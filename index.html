Characters removed
The instruction is still readable — on purpose.

Quietly rewriting third-party text would hide the attack from the human reading the output, and phrase-matching for jailbreaks misses rewordings while mangling legitimate bug reports. What's removed is only what hides: zero-width, bidi-override and ANSI characters. What stops the attack is the previous section — as viewer, the tool this payload names was never registered, so there is nothing to call. Telegram stays dry-run until a human sets TELEGRAM_DRY_RUN=false.

Why an envelope instead of an exception

A model can't act on a stack trace, and a crash in one source shouldn't take the others with it. Every tool answers with the same shape, so the client can tell "wait 42 seconds" apart from "this will never work" without parsing prose.

Unexpected exceptions become internal with a generic message: exception text can carry tokens, so detail stays in the server log.
